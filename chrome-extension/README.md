# Antigravity ASCII Animals — Chrome Extension

> **Living procedural ASCII animal backgrounds, obsidian black New Tab, and instant species dropdown switcher for Google Chrome, Brave, Microsoft Edge, and Arc.**

Brings the procedural ASCII art ecosystem from Google Antigravity directly to Chrome without needing root permissions, systemd daemons, or Python binary pak patching.

---

## Features

- **Living Procedural Cellular ASCII Engine**: 8 official species simulation:
  - 🦋 **Butterfly** (`1`) — Blue morpho flutter and gliding
  - 🐟 **Koi** (`2`) — Calico S-curve spine motion with click-to-feed
  - 🪼 **Jellyfish** (`3`) — Bioluminescent bell pulsation
  - 🦗 **Dragonfly** (`4`) — Emerald hawker with dart-and-zip mechanics
  - 🐸 **Frog** (`5`) — Leopard frog with kick-swims
  - 🦩 **Crane** (`6`) — Red-crowned cranes in coordinated flock flight
  - 🦀 **Crab** (`7`) — Shore crab scuttling bursts with pinching claws
  - 🌊 **Manta Ray** (`8`) — Ocean manta with undulating wing sweeps
- **Obsidian Black New Tab (`#07080c`)**:
  - Fullscreen ASCII canvas running at smooth 36–60fps
  - Minimalist Google search bar with instant URL detection
  - Glass quick-links (YouTube, GitHub, Gmail, Reddit, X/Twitter, Claude)
  - Time & Date display
- **Interactive Controls**:
  - Top-right species dropdown menu with glowing accent indicators
  - Keyboard hotkeys: press `1` through `8` to switch species instantly
  - Press `H` to toggle UI visibility for pure fullscreen wallpaper mode
  - Click anywhere on empty space to startle creatures / feed Koi
- **Toolbar Action Popup**:
  - Click the extension icon in Chrome toolbar to switch species anytime
  - Optional toggle to apply Obsidian Black + ASCII background to Google Homepage (`google.com`)
- **Offline & Zero-Telemetry**:
  - 100% local, self-contained Manifest V3
  - Zero external network requests, zero telemetry, no tracking

## 1-Minute Installation Guide

Works on **macOS**, **Windows**, and **Linux** with any Chromium browser (Chrome, Brave, Edge, Arc, Opera, Vivaldi):

1. **Get the extension**:
   - Unzip `antigravity-ascii-animals-chrome.zip`, or clone this repo.
2. **Open Extensions in Chrome**:
   - Navigate to `chrome://extensions` in your address bar.
3. **Enable Developer Mode**:
   - Turn on the **Developer mode** toggle in the top-right corner.
4. **Load the Extension**:
   - Click **Load unpacked** (top-left).
   - Select the `chrome-extension` folder.
5. **Enjoy**:
   - Press `Ctrl + T` (or `Cmd + T` on Mac) to open a New Tab!
